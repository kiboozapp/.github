# Kibooz

## About

Kibooz is an app for kindergartens. Teachers record the moods of children, parents follow them, and sorting trash earns points on a class leaderboard.

## Repositories

| Repository | What it holds |
|---|---|
| [kibooz-backend](https://github.com/kiboozapp/kibooz-backend) | The REST API, written in Go |

The Android app is developed in a separate repository.
