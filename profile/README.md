# Kibooz

## About

Kibooz is an app for kindergartens. Teachers record the moods of children, parents follow them, and sorting trash earns points on a class leaderboard. Teachers and parents can also chat in the app.

## Repositories

| Repository | What it holds |
|---|---|
| [kibooz-app](https://github.com/kiboozapp/kibooz-app) | The Android app, written in Kotlin |
| [kibooz-backend](https://github.com/kiboozapp/kibooz-backend) | The REST API, written in Go |

The code of both repositories is under GPL-3.0.
